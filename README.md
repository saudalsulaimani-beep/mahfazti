# محفظتي 1

تطبيق ويب لمتابعة محفظة أسهم السوق السعودي (تداول). تقدر تضيفه للشاشة الرئيسية في جوالك.

- **الأسعار** تجي من Yahoo Finance، وتتحدث تلقائياً كل ٥ دقائق تقريباً وقت التداول عن طريق GitHub Actions (`.github/workflows/prices.yml`).
- **بياناتك الشخصية** (الكميات، السيولة، المستويات) تنحفظ في متصفح جهازك فقط، وما تنرفع للمستودع أبداً.
- **قائمة الأسهم المتابعة** في `data/tickers.json`.
- **التطبيق يفتح من Netlify** (الواجهة + المحرك في `netlify/`: الإشعارات، رسم اليوم، الأسعار الحية). GitHub يبقى مكان الكود ويحدّث ملفات الأسعار والتحليل، والتطبيق يقراها من GitHub Pages. Netlify ما ينشر إلا لو تغيّر التطبيق نفسه (`netlify.toml`) عشان ما يخلص رصيد الخطة المجانية.
- **الودجيت**: من التطبيق ← الإعدادات ← التنبيهات ← «ودجيت»، يشتغل عن طريق تطبيق Scriptable.

أداة متابعة وتعلّم شخصية، مو توصية استثمارية.
